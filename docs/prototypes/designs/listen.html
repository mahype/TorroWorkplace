Lists in three designs

Draft for L.32 (#291): the task list and the calendar agenda drawn with Standard, Compact and Console, dark and light. One script builds the same rows from the same data for all three; a design only changes sizes and how the list is drawn, never where something stands. Colours are the Torro scheme in every design.

  • Standard and Compact draw rows with hairlines between them; the selected row is selected with a 2 px bar in accent at the left.
  • Console draws every entry on one line, without lines; the selected row is filled with accent, its text and symbols in on_accent.
  • No column headings, no capitals. Every row has the same cells in the same order in all three designs.
