Torro Notes – Entwürfe

Die Notizen-App torronotes nach dem Konzept in docs/notizen.md (Issue #602), im Standard der Suite (Skill torro-design). Eine Gestaltungsrichtung; nur der Editor zeigt zwei Formen: den Umschalter Edit / Preview (Entscheidung 8) und die Live-Vorschau, die die Recherche empfiehlt (Vorschlag zu Entscheidung 8, siehe Entscheidung 11). Jeder Rahmen zeigt app.html in der echten Fenstergröße, verkleinert. Alles öffnet ohne Netz.

Parameter von app.html: size=bar|mini|s|m|l, theme=light|dark, open=list|edit|preview|live|conflict|readonly|offline|empty|save.
