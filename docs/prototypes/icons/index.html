Icons der Suite: drei Entwürfe zur Auswahl

Ein Set für alle sieben Apps (AP.6, Issue #279). Gemeinsam: die Grundform der macOS-Vorlage (Fläche 1024, Körper 824 mit 100 Rand, durchgehend gerundete Ecken, leichter Schatten), ein Motiv je App auf einem 24er-Raster mit Strich 3 (72 px auf 1024, damit es bei 16 und 32 px noch trägt) und Torro-Rot #D50C0C als Markenfarbe. Die Varianten unterscheiden sich nur in Fläche, Motivfarbe und Tiefe.

Bitte eine Variante im Issue nennen (red, light oder gradient); danach baut AP.7 sie ein.

Überblick

Die Pixelansicht zeichnet das Icon in echter Größe (1x) und vergrößert es viermal bzw. zweimal, so wie ein Bildschirm ohne Retina es zeigt. Auf Retina-Bildschirmen zeigen die Spalten 16 und 32 doppelt so viele Pixel. Das Dock zeigt drei neutrale Flächen als fremde Apps zum Vergleich; mit der Maus über einem Icon erscheint der Name.
