Workspaces: Kürzel, Start und ein Dialog für alles

Entwürfe zum Issue „Workspaces: Kürzel, Laden beim Start und ein Dialog zum Speichern und Bearbeiten“. Oberflächentexte englisch wie in der Software, Erklärungen deutsch. Beispiel-Daten: Hyprland mit zwei Bildschirmen.

Einstellungen › Workspaces

Fenstermanager oben, Vorlagen mit Taste und Start

  • Neue Gruppe Window manager: welcher erkannt ist, Version, Zahl der Bildschirme, Zustand der Kürzel.
  • Jede Vorlage zeigt ihre Taste und, falls gesetzt, „At startup · DP-1“.
  • Sortiert nach Taste, ohne Taste nach Name.
  • Eine sichtbare Aktion je Zeile (Load), der Rest im „…“-Menü: Edit…, Update from current workspace, Delete. Das Umbenennen in der Zeile entfällt.
  • Primärknopf Save workspace… öffnet denselben Dialog wie im Tray.

Einstellungen › Workspaces › Edit…

Ein Dialog für alle Einstellungen einer Vorlage

  • Name, Shortcut und At startup auf einen Blick, gespeichert mit einem Klick.
  • Tasten 1 … 0 als Reihe; belegte Tasten tragen einen Punkt und den Namen der Vorlage darunter.
  • Wird eine belegte Taste gewählt, sagt der Hinweis, dass sie umzieht. Kein zweiter Dialog.
  • Der Bildschirm wird als kleine Skizze in echten Proportionen gewählt; „Screen the template was saved on“ ist die Vorgabe.
  • Abschnitte mit Titel, damit später mehr dazukommen kann (z. B. Verhalten je Fenster).

Tray-Menü

Laden mit Taste im Blick, Speichern mit Dialog

  • Kopf der Gruppe nennt den Fenstermanager.
  • Vorlagen direkt in der ersten Ebene, Taste als Hinweis rechts. Klick lädt (wie Load), das Untermenü bietet Replace windows.
  • Save workspace… mit Auslassungspunkten: Es öffnet den Dialog rechts statt still „Workspace 4, 19.10.“ zu speichern.
  • Manage workspaces… öffnet Einstellungen › Workspaces.
  • Update und Delete wandern aus dem Tray in die Einstellungen.

Zustände

Kein Fenstermanager, Taste belegt, schmale Kachel

  • Fehlt der Fenstermanager, sagt die Gruppe, welcher erwartet wird und was zu tun ist. Laden, Speichern und Kürzel sind dann aus.
  • Kann eine Taste nicht angemeldet werden (vom System belegt), steht das an der Zeile „Shortcuts“, nicht still.
  • In schmalen Fenstern (unter 600) stehen die Tasten im Dialog in zwei Reihen, Bildschirme untereinander.
