Fotos und Bilderrahmen

Die Foto-App baut auf Nextcloud Photos auf. Recognize (Personen) und Memories (Karte) kommen dazu, wenn sie auf dem Server laufen. In Version 1 kann man ansehen und ordnen: Zeitleiste, Alben, Personen, Orte und Favoriten. Bearbeitet werden nur Datum, Ort und Tags; hochgeladen wird noch nichts. Dazu kommt der Bilderrahmen, eine Kachel mit einem Foto oder einer Diashow. Ein Klick auf eine Karte öffnet den Entwurf in voller Größe.

Bilderrahmen

Eine kleine Nebenanwendung für Kacheln im Workspace. Sie zeigt ein Foto oder eine Diashow aus einem Album, einer Person, einem Ort, den Favoriten oder „An diesem Tag“. Im Ruhezustand ist nur das Bild zu sehen. Beim Überfahren erscheinen Quelle, Vor/Pause/Zurück und die Einstellungen. Die Wahl gehört zum Fenster, so bringt eine Workspace-Vorlage den Rahmen mit demselben Album zurück.

So könnte ein Workspace aussehen: mehrere Rahmen neben anderen Kacheln (32:9, verkleinert)

Wie der Rahmen zu API und MCP passt

  • Oberfläche: Rahmen-Fenster mit Einstellungskarte. Aus der Foto-App heraus: „Show in frame“ an einem Album, einer Person oder einem Ort.
  • API: Der Rahmen holt seine Bilder mit den Lese-Befehlen der Foto-App (photos.list_photos, photos.get_preview). Ein Fenster öffnet apps.open_app mit Startparametern, z. B. torroframe --album "Tuscany 2024" --every 1m --shuffle. Vorher gecachte Vorschaubilder machen den Rahmen offline-fest.
  • MCP: Das gibt es schon: apps_open_app mit Parametern („Zeig mir die Toskana-Fotos als Diashow rechts“). Der Assistent sieht dabei nur, welches Album läuft, nicht die Bilder. Das Recht „Bildinhalte“ bleibt davon getrennt.
  • Dauerbetrieb: Nur alle n Sekunden ein Bildwechsel mit kurzem Überblenden. Kein Ken-Burns-Zoom (er verbraucht die GPU ständig) und keine Bedienelemente ohne Mauszeiger. Bilder werden in Kachelgröße geladen, nicht als Original.
