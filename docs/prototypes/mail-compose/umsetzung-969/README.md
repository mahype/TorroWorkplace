# Schreibfenster mit Squire (#969): Seitenbilder

Die drei Bilder zeigen **die Seite des neuen Schreibfensters** (`crates/torroinbox/assets/compose/`) mit Beispieldaten,
gerendert in einem Browser-Rahmen mit nachgebauter Brücke (`window.torroCompose.receive`), **nicht das native
Fenster**: In der Umgebung dieser Umsetzung war keine Bildschirmaufnahme erlaubt. Das echte Fenster wurde auf macOS
gestartet und mit dem eingebauten Selbsttest geprüft (`TORRO_COMPOSE_SELFTEST=1`, siehe `docs/mail.md`), Bilder davon
fehlen. Vorher-Bilder des alten Iced-Editors gibt es hier nicht; sie müssen auf `main` mit
`.claude/skills/torro-design/shots.sh` aufgenommen werden (offen, #976).
