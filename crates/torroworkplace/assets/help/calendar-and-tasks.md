# Calendar and tasks

**Calendar** shows your events, **Tasks** your to-dos. Both work over CalDAV: Nextcloud first, also iCloud reminders and other servers, or the CalDAV of a mail provider (see the topic "accounts").

## Calendar

The Calendar settings have "Calendars", "Reminders", "Night" and "Working hours". Reminders are a quiet notification or full screen. They are stored with the event, so they also reach your phone, and each one is an entry in the Notification Hub too. Tray menu › "Pause reminders" holds them back for an hour or until tomorrow.

The calendar does not show tasks yet.

## Tasks

"New task" and "New task list"; the Tasks settings have "Lists".

### GitHub issues as tasks

With a GitHub account, "New GitHub filter list" makes a list from a GitHub search: paste a search or the address of a GitHub issue list, or start from a preset such as "Assigned to me" or "Review requested". Several searches in one list are combined. Single issues can be pinned. "Edit filter list" changes it; "Open on GitHub" opens an item there.

Issues and pull requests show as tasks: closed or merged counts as done, sub-issues are subtasks, labels are categories, and the date of the milestone is the due date. An issue can also be added to one of your own lists as a linked task with its own date and order.

## From the inbox

An item of the Notification Hub or a mail can become a task or an event: "Make task" or "Make event".
